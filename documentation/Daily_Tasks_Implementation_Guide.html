Daily Tasks Automation — Implementation Guide

Build, install, and run the Daily Tasks Automation dashboard (calendar_automate.exe or Python entry script) with satellite tools: Laundry, WhatsApp Poll, and YouTube Transcribe.

This document contains no API keys, tokens, OAuth JSON bodies, or real secret paths. Supply your own property_files offline.

What you are shipping

  • Main app: Tkinter dashboard — Calendar, Contacts, Laundry, WhatsApp Poll, Volleyball Low Turnout, YouTube tools.
  • Packaging: PyInstaller onefile → calendar_automate.exe (windowed, no console).
  • Satellite automations: Stay as folders under <REPO_ROOT>; the frozen .exe launches their .bat files in a new console — it is not a Python interpreter for those scripts.

Build the Windows .exe (PyInstaller)

Build steps
  1. Use one Python 3.12+ interpreter for install and build.
  2. Install runtime deps + PyInstaller (see command below).
  3. From google_calendar_and_contacts_automate/, run PyInstaller on google_calendar_and_contacts_automate.spec.
  4. Output: google_calendar_and_contacts_automate\dist\calendar_automate.exe
Do not use calendar_automate.spec in the same folder — it is a legacy spec with stale absolute paths.

Deploy and property_files

Runtime configuration (no secrets in this guide)

Frozen builds look for property_files beside the .exe first, then the PyInstaller unpack tree if files were bundled at build time.

Typical filenames only (create offline with your own values):

  • calendar_api_properties.properties
  • google_desktop_oauth_client_contacts_api.json (OAuth client metadata from Google Cloud Console)
  • calendar-automate-srvc-account-ref-file.json (if using service account mode)
  • token.pickle (often created after first sign-in; may also live under %APPDATA%)
Never embed real credentials in HTML, git, or the PyInstaller bundle unless you intend to. Prefer property_files next to the installed .exe.

Set TASKS_AUTOMATION_ROOT=<REPO_ROOT> so Laundry / WhatsApp / YouTube buttons find their .bat files. The launcher shortcut (below) sets this automatically.

Desktop shortcut & single-shot launch

One-click desktop access
  1. Build (first time or after dashboard changes): documentation\build_daily_tasks.bat — installs deps and builds dist\calendar_automate.exe.
  2. From <REPO_ROOT>\documentation\, run create_desktop_shortcut.bat (or build_daily_tasks.bat --shortcut).
  3. This creates Daily Tasks Automation.lnk on your Desktop.
  4. The shortcut targets launch_daily_tasks_dashboard.bat, which:
    • Sets TASKS_AUTOMATION_ROOT to the repo root
    • Starts dist\calendar_automate.exe if built, otherwise py -3 google_calendar_and_contacts_automate.py
Dashboard WhatsApp buttons: WhatsApp Poll (manual) and Volleyball Low Turnout (Friday) launch WhatsApp_Web_Poll\*.bat. Each calls start_edge_cdp.bat — if Edge is closed, it starts Edge with web.whatsapp.com in profile C:\edge-cdp.
The .exe is the dashboard only. WhatsApp, laundry, and YouTube still need their repo folders and Python for the .bat scripts. Keep the full tasks_automation tree on disk.
Recommended install layout:
Keep the full tasks_automation tree on disk. Place property_files next to calendar_automate.exe if you copy the .exe to a separate install folder — or run from the repo dist folder during development.

Dashboard vs scheduled launches

Manual (dashboard) vs automatic (Task Scheduler)
FeatureDashboard buttonScheduled / double-click .bat
WhatsApp Poll GUI asks contact name and send vs dry-run, then runs run_whatsapp_poll.bat with SKIP_PROMPTS=1 run_whatsapp_poll_scheduled.bat — Thursday hourly 8 AM–11 PM; retries until success; weather + poll
Volleyball Low Turnout GUI: check latest poll (< 6 Yes → cancel) or send cancel now; runs run_whatsapp_turnout_check.bat or run_whatsapp_low_turnout_cancel.bat run_whatsapp_turnout_check_scheduled.bat — Friday 3 PM + 4 PM retry; reads poll; weather gate
Laundry Confirmation dialog, then run_laundry.bat in new console Double-click run_laundry.bat or Hermes/cron wrapper
YouTube Console prompts in run_transcribe.bat Same batch files
Dashboard → WhatsApp Poll button → Tk dialog: contact + send/dry-run → run_whatsapp_poll.bat (SKIP_PROMPTS=1, CONTACT, SEND env) → start_edge_cdp.bat → whatsapp_poll.py Dashboard → Volleyball Low Turnout button → Tk dialog: check poll vs force cancel + send/dry-run → run_whatsapp_turnout_check.bat OR run_whatsapp_low_turnout_cancel.bat Dashboard → Laundry button → Tk Yes/No confirm → run_laundry.bat → start_edge_cdp.bat → _cdp_driver.py Task Scheduler (Thursday hourly) → run_whatsapp_poll_scheduled.bat → schedule_gate.py (success/failed status, retry until 11 PM) → fixed CONTACT, SEND=1, logs Task Scheduler (Friday 3 PM / 4 PM) → run_whatsapp_turnout_check_scheduled.bat → read poll Yes votes; cancel if < 6 and weather OK

Troubleshooting

Common issues
SymptomWhat to do
Laundry / WhatsApp button “not found”Set TASKS_AUTOMATION_ROOT to <REPO_ROOT> or use the desktop launcher shortcut.
Properties file missingAdd property_files beside calendar_automate.exe with your offline config.
CDP port in useClose all Chrome/Edge; run the correct start_edge_cdp.bat.
Scheduled poll ran twiceCheck whatsapp_poll_status.json; success stops hourly retries. See WhatsApp schedule HTML docs.
Poll log incomplete (no [wapoll] lines)WhatsApp slow to load; hourly retry or run view_logs.bat. Avoid mouse in Edge during run.
Friday cancel not sentYes votes may be ≥ 6, or weather cancelled game, or turnout already succeeded. See Friday turnout HTML doc.
