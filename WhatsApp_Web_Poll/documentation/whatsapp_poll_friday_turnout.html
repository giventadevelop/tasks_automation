Friday Turnout Check — Low Player Cancellation

On Friday game day, this automation opens the Volleyball Friday WhatsApp group, finds the latest volleyball poll, counts Yes votes, and decides whether to send a low-turnout cancellation message.

Season gate: May 12 – Oct 30 (same as Thursday poll). Installed by install_whatsapp_poll_task.bat.

Decision logic

1. schedule_gate_turnout.py — Friday? in season? 3 or 4 PM? not already success today? 2. weather_check_today() — today's 4–8 PM at Lake Hiawatha → if RAIN or temp out of range: skip low-turnout message (game already off / weather cancel) 3. Open Volleyball Friday chat, scroll to latest poll 4. Read Yes / No vote counts → if Yes ≥ 6: done, no message → if Yes < 6 AND weather OK: send LOW_TURNOUT_MSG 5. Mark success or failed in whatsapp_turnout_status.json

Vote threshold

Default MIN_PLAYERS=6. The poll must show at least 6 Yes votes to play. Example: Yes=4, No=5 → cancel message is sent (if weather is fine).

Low-turnout message (default)

Today's volleyball game CANCELED : Not enough people Hey folks, today's volleyball game at the park's off—doesn't look like we've got enough people. No worries, we'll aim for next week. Catch you then!

Override with env LOW_TURNOUT_MSG.

Weather on Friday

Unlike Thursday (which checks tomorrow for the poll), Friday turnout checks today's 4–8 PM forecast. If weather would cancel the game (rain ≥50% PoP or temp outside 65–92°F), the low-turnout message is not sent — players should already know from Thursday's weather cancel or conditions.

Environment variables

  • MIN_PLAYERS — default 6
  • LOW_TURNOUT_MSG — cancellation text
  • ACTION=check_turnout — set by turnout scripts
  • TURNOUT_RUN_HOURS=15,16 — gate hours (3 PM, 4 PM)
  • SKIP_WEATHER=1 — skip Friday weather pre-check
