Friday Turnout Check — Weather + Player Count

On Friday game day, this automation opens the Volleyball Friday WhatsApp group, checks today's weather (4–8 PM at Lake Hiawatha), reads the latest volleyball poll, and sends the appropriate message: weather cancel, low-turnout cancel, or all-clear let's play.

Keeps trying until a message is sent (go, weather cancel, or low-turnout cancel) or the window ends at 5 PM. If the PC was off, StartWhenAvailable runs the next trigger when it comes back (still within the window). After success today, further triggers skip.

Decision logic

1. schedule_gate_turnout.py — Friday? in season? 3:00–5:00 PM? message not already sent today? 2. weather_check_today() — today's 4–8 PM at Lake Hiawatha → if RAIN: send CANCEL_MSG + rainy image → if temp > 90°F: send HOT_CANCEL_MSG + hot image → if temp < 65°F: send COLD_CANCEL_MSG + cold image 3. If weather OK: open Volleyball Friday chat, read latest poll Yes / No counts → if Yes ≥ 6: send GO_MSG (all-clear — let's play) → if Yes < 6: send LOW_TURNOUT_MSG 4. Mark success or failed in whatsapp_turnout_status.json → after success (any message sent), later 20-min triggers skip that Friday → after failure, retry at next 20-min slot until 5 PM

All-clear message (default)

✅ Everything looks good! Both the weather and the number of people are good for today's volleyball at the park. Let's play! See you at Lake Hiawatha — 6:00 PM.

Override with env GO_MSG.

Vote threshold

Default MIN_PLAYERS=6. The poll must show at least 6 Yes votes to play. Example: Yes=4, No=5 → cancel message is sent (if weather is fine).

Low-turnout message (default)

Today's volleyball game CANCELED : Not enough people Hey folks, today's volleyball game at the park's off—doesn't look like we've got enough people. No worries, we'll aim for next week. Catch you then!

Override with env LOW_TURNOUT_MSG.

Weather on Friday

Unlike Thursday (which checks tomorrow for the poll), Friday turnout checks today's 4–8 PM forecast. Bad weather sends the appropriate weather cancellation message (rain or temperature). Good weather continues to the poll vote check.

Environment variables

  • MIN_PLAYERS — default 6
  • LOW_TURNOUT_MSG — cancellation text
  • GO_MSG — all-clear let's-play text
  • CANCEL_MSG / TEMP_CANCEL_MSG — weather cancellation texts
  • ACTION=check_turnout — set by turnout scripts
  • TURNOUT_WINDOW_START_HOUR / TURNOUT_WINDOW_END_HOUR — default 15–17 (3–5 PM)
  • TURNOUT_INTERVAL_MINUTES — documented default 20 (set in Task Scheduler /ri 20)
  • SKIP_WEATHER=1 — skip Friday weather pre-check
