Scheduled load delays

When SCHEDULED=1, the script waits longer for WhatsApp Web to finish loading chats:

  • 300s session timeout
  • 25s settle after chat list appears
  • 5s pause before contact search
  • 10s Edge warmup in batch before Python starts
  • Requires at least 3 visible chat rows

Avoid using the mouse in Edge (C:\edge-cdp) during scheduled runs.

Incomplete run pattern
If the log stops after [ok] Edge CDP is up. with no [wapoll] lines, the Python step did not complete. Thursday hourly retry should try again; check status JSON and scripts_batch_files\whatsapp_poll\view_logs.bat.
